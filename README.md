# rdsgn – Redesign Digital

This repository contains the code for **rdsgn (Redesign Digital)** –  
Jitesh's personal **playground, portfolio, SEO blog, and service website**.

The site is built with **HTML, CSS and JavaScript** and is designed to be hosted on **GitHub Pages**.

---

## 🎯 Purpose

- Personal website & online identity  
- Portfolio for **SEO** and **Web Development** work  
- Blog for **SEO and website-building notes**  
- Simple service page for:
  - SEO setup & optimization  
  - Website design & development  
- Playground for experiments (UI, games, SEO tests)

---

## 🔧 Tech Stack

- **HTML5** – structure and content  
- **CSS3** – styling, responsive layout, theme variables  
- **Vanilla JavaScript (ES6)** – mobile navigation, dynamic year in footer  
- **GitHub Pages** – hosting (static site)

No backend, no database, no PHP – completely static.
